# AI Mock Interview Platform

An AI-powered full-stack mock interview platform designed to help users practice technical and behavioral interviews through realistic interview sessions, AI-generated questions, feedback, voice interaction, and coding assessments.

## 🚀 Features

* AI-powered mock interviews
* Resume-based interview question generation
* AI-generated interview feedback
* Voice-based interview experience
* Coding assessment functionality
* User authentication
* Interview history and data storage
* Responsive web interface
* REST API-based backend

## 🔄 How It Works

1. The user signs up and logs into the platform.
2. The user provides interview-related information and/or a resume.
3. The application generates relevant interview questions using the Gemini API.
4. The user participates in a mock interview.
5. The platform supports voice-based interview interaction and coding assessments.
6. AI-generated feedback is provided based on the interview interaction.
7. Interview information is stored for future reference.
